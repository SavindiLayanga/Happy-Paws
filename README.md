H# 🐾 Happy Paws - Pet Care Website

Happy Paws is a modern and responsive pet care website designed for pet clinics, grooming centers, boarding services, adoption centers, and pet care businesses.

## 🌟 Features

- Responsive homepage with hero section
- About section with mission and vision
- Pet care services cards
- Pet gallery with filter options
- Appointment booking form
- Customer testimonials carousel
- Blog section for pet care tips
- FAQ accordion
- Contact section with Google Map
- Newsletter subscription
- Dark mode toggle
- Scroll-to-top button
- Smooth animations
- Mobile-friendly navigation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Font Awesome Icons
